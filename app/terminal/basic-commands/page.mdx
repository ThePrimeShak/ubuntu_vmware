# Basic Terminal Commands

Use these examples in a disposable lab directory first. Paths, package names, interfaces, and services differ between systems.

On minimal installations, tools such as `curl`, `rsync`, and the SSH client may need to be installed first. A log such as `/var/log/syslog` exists only when the system is configured to write it; on a systemd installation you can also read logs with `journalctl`.

## Navigation and files

| Command | Example                     | Purpose                                                 |
| ------- | --------------------------- | ------------------------------------------------------- |
| `pwd`   | `pwd`                       | Print the current working directory                     |
| `ls`    | `ls -lah`                   | List entries, including hidden files and readable sizes |
| `cd`    | `cd ~/Documents`            | Change directory                                        |
| `mkdir` | `mkdir -p lab/notes`        | Create directories, including missing parents           |
| `touch` | `touch notes.txt`           | Create an empty file or update its timestamp            |
| `cp`    | `cp -i notes.txt notes.bak` | Copy and ask before overwriting                         |
| `mv`    | `mv -i old.txt new.txt`     | Move or rename and ask before overwriting               |
| `rm`    | `rm -i draft.txt`           | Remove a file after confirmation                        |
| `file`  | `file archive.tar.gz`       | Identify a file's type                                  |
| `stat`  | `stat notes.txt`            | Show detailed file metadata                             |

## Read and search text

| Command | Example                       | Purpose                                             |
| ------- | ----------------------------- | --------------------------------------------------- |
| `cat`   | `cat /etc/os-release`         | Print a short file                                  |
| `less`  | `less /var/log/syslog`        | Read a long file page by page; press `q` to quit    |
| `head`  | `head -n 20 file.txt`         | Show the first 20 lines                             |
| `tail`  | `tail -f app.log`             | Follow new lines appended to a file                 |
| `grep`  | `grep -Rni "error" logs/`     | Search recursively with line numbers, ignoring case |
| `find`  | `find . -type f -name "*.md"` | Find files by criteria                              |
| `wc`    | `wc -l file.txt`              | Count lines                                         |
| `sort`  | `sort names.txt`              | Sort lines                                          |
| `uniq`  | `sort names.txt \| uniq -c`   | Count adjacent duplicate lines after sorting        |

## Users and permissions

| Command  | Example                           | Purpose                                  |
| -------- | --------------------------------- | ---------------------------------------- |
| `whoami` | `whoami`                          | Print the effective username             |
| `id`     | `id`                              | Show user and group IDs                  |
| `groups` | `groups`                          | Show group memberships                   |
| `chmod`  | `chmod u+x script.sh`             | Add execute permission for the owner     |
| `chown`  | `sudo chown student:student file` | Change owner and group                   |
| `sudo`   | `sudo apt update`                 | Run one command with elevated privileges |

Numeric permissions such as `644` are compact, but symbolic changes like `u+x` are often clearer while learning.

## Packages and services

| Command             | Example                                | Purpose                                |
| ------------------- | -------------------------------------- | -------------------------------------- |
| `apt search`        | `apt search tree`                      | Search APT package metadata            |
| `apt show`          | `apt show tree`                        | Inspect a package before installation  |
| `apt install`       | `sudo apt install tree`                | Install a package and its dependencies |
| `apt remove`        | `sudo apt remove tree`                 | Remove a package                       |
| `systemctl status`  | `systemctl status ssh`                 | Inspect a systemd service              |
| `systemctl restart` | `sudo systemctl restart ssh`           | Restart a service                      |
| `journalctl`        | `sudo journalctl -u ssh --since today` | Read service logs from today           |

Do not add `-y` until you are comfortable reviewing package-manager changes before confirming them.

## Processes and system resources

| Command | Example              | Purpose                                   |
| ------- | -------------------- | ----------------------------------------- |
| `ps`    | `ps aux`             | Take a snapshot of running processes      |
| `top`   | `top`                | Monitor processes interactively           |
| `pgrep` | `pgrep -a ssh`       | Find matching process IDs and commands    |
| `kill`  | `kill 1234`          | Request graceful termination with SIGTERM |
| `free`  | `free -h`            | Show RAM and swap usage                   |
| `df`    | `df -h`              | Show filesystem capacity                  |
| `du`    | `du -sh ~/Downloads` | Summarise directory size                  |
| `lsblk` | `lsblk -f`           | Show block devices and filesystems        |
| `uname` | `uname -a`           | Show kernel and architecture information  |

Use `kill -9` only as a last resort because SIGKILL prevents a process from cleaning up.

## Networking and remote access

| Command      | Example                                    | Purpose                                        |
| ------------ | ------------------------------------------ | ---------------------------------------------- |
| `ip address` | `ip address`                               | Show network interfaces and addresses          |
| `ip route`   | `ip route`                                 | Show routing decisions and the default gateway |
| `ping`       | `ping -c 4 1.1.1.1`                        | Test IP reachability; some networks block it   |
| `ss`         | `ss -tulpen`                               | Show listening TCP/UDP sockets                 |
| `curl`       | `curl -I https://example.com`              | Fetch HTTP response headers                    |
| `ssh`        | `ssh student@192.168.1.20`                 | Open an encrypted remote shell                 |
| `scp`        | `scp report.txt student@host:~/`           | Copy a file over SSH                           |
| `rsync`      | `rsync -av --dry-run source/ destination/` | Preview an incremental copy                    |

## Help and command history

| Command      | Example              | Purpose                                                               |
| ------------ | -------------------- | --------------------------------------------------------------------- |
| `man`        | `man ls`             | Open a command's manual page                                          |
| `--help`     | `ls --help`          | Show concise usage help                                               |
| `history`    | `history`            | Show shell command history                                            |
| `command -v` | `command -v python3` | Show how the shell resolves a command, including builtins and aliases |
| `type`       | `type cd`            | Explain whether a name is a binary, alias, or shell builtin           |

## A safe practice exercise

```bash
mkdir -p ~/os-lab/practice
cd ~/os-lab/practice
printf "Ubuntu\nDebian\nUbuntu\n" > distributions.txt
sort distributions.txt | uniq -c
cp -i distributions.txt distributions.bak
ls -lah
```

This exercise creates a disposable directory, writes a small file, counts repeated lines, makes a backup, and lists the result without requiring administrator privileges.
