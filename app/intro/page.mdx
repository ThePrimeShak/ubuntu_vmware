## About this project

This documentation was created for a university **Operating Systems Laboratory** course. It turns the lab material into a structured, visual guide that students can follow before, during, and after class.

The project also demonstrates a modern documentation workflow using **Next.js**, **Nextra**, TypeScript, and GitHub.

<ProjectHighlights />

## Recommended learning path

1. Read **Linux Basics** to understand the kernel, distributions, and common use cases.
2. Review **Virtual Machines** and install VMware Workstation.
3. Create a VM and install either **Ubuntu** or **Debian**.
4. Learn the difference between a terminal and a shell, then practise the command reference.
5. Finish with the Linux Essentials pages on root access, swap, and dual boot.

> The screenshots can differ slightly across Ubuntu, Debian, and VMware releases. Focus on the option names and purpose of each step rather than the exact colours or layout.

## Who this guide is for

- University students in computer engineering, IT, or related programmes
- Beginners who want to explore Linux without changing their main operating system
- Instructors who need a concise reference for an operating-systems lab
- Developers who want a disposable Linux environment for practice

No previous Linux experience is required. Basic familiarity with files, folders, and installing desktop applications is enough.
