# Install VMware Workstation Pro on Windows

This guide covers the Windows installation flow. The screenshots show Workstation 17; button names and optional features can differ in newer releases.

## Before you begin

- Use a supported 64-bit version of Windows.
- Enable Intel VT-x or AMD-V in UEFI/BIOS if hardware virtualisation is disabled.
- Keep several gigabytes free for the application and at least 30 GB more for each Linux VM.
- Download software only from Broadcom's official portal.

## 1. Download the installer

Open Broadcom's official [VMware desktop hypervisor download instructions](https://knowledge.broadcom.com/external/article/368667/download-and-license-free-vmware-desktop.html). Sign in with a Broadcom Support Portal account, complete any required profile or trade-compliance details, accept the terms, and download the latest **VMware Workstation Pro for Windows** installer.

> Workstation Pro 17.5.2 and newer are available without a licence key for personal, educational, and commercial use. Avoid unofficial mirrors and modified installers.

## 2. Run the installer

1. Confirm that the downloaded file is a Windows `.exe` installer.
2. Double-click it and approve the Windows User Account Control prompt.
3. Select **Next** to begin.

## 3. Accept the licence agreement

Read the End User Licence Agreement, select the acceptance checkbox, and continue.

![VMware Workstation licence agreement](/images/vmware/step1.png)

## 4. Choose the destination and optional features

The default installation directory is suitable for most users. The illustrated version also offers to add VMware console tools to the system PATH; keep this enabled if you want to use those tools from a terminal. Other releases may offer different optional features.

![VMware Workstation destination folder](/images/vmware/step2.png)

Choose whether VMware may check for updates and whether to join the customer experience programme. These preferences can be changed later.

![VMware Workstation update and experience settings](/images/vmware/step3.png)

## 5. Create shortcuts and install

Select the desktop and Start menu shortcuts you want, then choose **Install**. Restart Windows if the installer asks you to do so.

![VMware Workstation shortcut options](/images/vmware/step4.png)

![VMware Workstation installation progress](/images/vmware/step5.png)

## 6. Start Workstation Pro

Launch VMware Workstation Pro from the Start menu. Current free releases do not require a licence key. If an older screen offers licensing choices, use the free-use option supported by that release rather than a trial or an unofficial key.

![VMware Workstation home screen](/images/vmware/step6.png)

## Troubleshooting

- **Virtualisation is unavailable:** enable Intel VT-x or AMD-V in UEFI/BIOS, then fully restart the computer.
- **A Hyper-V compatibility message appears:** install the latest Workstation release. Windows security features can change which hypervisor backend VMware uses.
- **The download is unavailable:** verify that the Broadcom profile and trade-compliance form are complete.
- **The VM is very slow:** reduce assigned resources, close heavy host applications, store VM files on an SSD, and check that hardware virtualisation is active.
