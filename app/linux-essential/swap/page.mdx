# Swap in Linux

**Swap** is storage space that the kernel can use for memory pages that do not currently need to remain in RAM. It can help the system keep useful file-cache data in RAM and can provide breathing room during short memory spikes. It is much slower than RAM and does not guarantee that an out-of-memory condition will never occur.

## Swap file and swap partition

- A **swap file** lives inside a filesystem and is easy to add or resize. Ubuntu commonly uses this approach.
- A **swap partition** is a dedicated disk partition. It remains useful for some layouts and installer choices but is less flexible to resize.

Both methods are valid. The workload, storage layout, hibernation needs, and system configuration matter more than the format.

## How much swap?

There is no universal “twice the RAM” rule for current systems. A development VM with 4 GB of RAM might use a 2–4 GB swap file, while a memory-heavy workload may need more. Systems intended to hibernate usually need enough swap for the memory image plus overhead and must be configured to resume from it.

Heavy, continuous swap activity—sometimes called thrashing—means performance will be poor. Reduce the workload or allocate more RAM rather than treating swap as equivalent memory.

## Inspect swap and memory

```bash
free -h
swapon --show
cat /proc/swaps
```

## Create a 2 GB swap file

This example is for a new swap file on a local **ext4** filesystem. First run `findmnt -no FSTYPE /`, `swapon --show`, and `sudo ls -ld /swapfile`. Continue only if the filesystem is ext4 and `/swapfile` does not exist. If it already exists, inspect the existing swap configuration instead of overwriting it. Btrfs and other filesystems need different handling; consult the [swapon manual](https://man7.org/linux/man-pages/man8/swapon.8.html).

Run each step separately and stop if any command fails:

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

Verify it with `swapon --show`. To activate it after reboot, add this exact line to `/etc/fstab` only after checking that another `/swapfile` entry does not already exist:

```text
/swapfile none swap sw 0 0
```

> `mkswap` overwrites swap metadata on its target. Never substitute a device path unless you have positively identified the intended partition.

## Swappiness

`vm.swappiness` influences how readily the kernel chooses swap relative to reclaiming other memory. It is a preference, not a percentage of RAM reserved for swap.

```bash
sysctl vm.swappiness
```

Change it only for a measured workload and document the reason; the distribution default is a sensible starting point for a lab VM.
