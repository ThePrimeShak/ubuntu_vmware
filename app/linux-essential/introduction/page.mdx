# Linux Essentials

This section explains four concepts that often appear during Linux installation and administration:

- **Root user:** the administrator account with unrestricted system privileges
- **Root directory (`/`):** the top of the Linux filesystem tree
- **Swap:** disk space that can hold memory pages and can support hibernation
- **Dual boot:** installing multiple operating systems on one physical computer

## Why these topics matter

They help you interpret installer choices, understand privilege boundaries, and avoid costly mistakes. In particular, root commands and physical-disk partitioning can permanently change data.

The virtual-machine installation in this project is safer than dual boot because it writes to a virtual disk file. Even so, read device names and commands carefully before confirming destructive actions.

## Suggested order

1. Learn the two meanings of root.
2. Understand how swap complements—but does not replace—RAM.
3. Read the dual-boot page only if you plan to install Linux on physical hardware.

> Create backups before storage or partition changes. A snapshot is useful for a VM, but it is not a substitute for a backup stored on another device.
