# Why Debian?

## What Debian is

Debian is a community-developed GNU/Linux distribution known for its Social Contract, broad architecture support, large package repositories, and conservative stable releases. Ubuntu and many other distributions are derived from Debian.

As of November 17, 2026, Debian 13 “trixie” is the stable release, as listed on the [official release page](https://www.debian.org/releases/). Because version numbers change, always confirm the current stable image on the [official Debian download page](https://www.debian.org/distrib/).

## Debian release branches

| Branch           | Purpose                                                          | Appropriate for beginners?                          |
| ---------------- | ---------------------------------------------------------------- | --------------------------------------------------- |
| Stable           | Current production release with security and important bug fixes | Yes; recommended for this lab                       |
| Testing          | Packages being prepared for the next stable release              | Only with an understanding of its support model     |
| Unstable (`sid`) | Active package development and integration                       | No; intended for experienced users and contributors |

“Stable” describes Debian's change policy, not an absence of bugs. Security updates still need to be installed regularly.

## Why include Debian in this project?

- It exposes students to a more distribution-neutral Linux environment.
- Its installer clearly introduces networking, users, partitions, package mirrors, and task selection.
- It demonstrates the relationship between a distribution, its repositories, and downstream systems such as Ubuntu.
- The stable branch is predictable and suitable for repeatable lab exercises.

## Debian and Ubuntu compared

Both systems use APT and `.deb` packages. Debian is governed by its project and prioritises free software and stable release behaviour. Ubuntu follows its own fixed release schedule, supplies different defaults and tooling, and offers Canonical services and support.

Neither is universally “more pure” or “more educational.” They make different policy and usability choices. Ubuntu is usually simpler for a first desktop VM; Debian is valuable for seeing another installer and a less customised base system.
