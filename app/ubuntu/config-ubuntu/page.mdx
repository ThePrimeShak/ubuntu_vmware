# Install Ubuntu Desktop

These steps run inside the virtual machine. The screenshots show Ubuntu 24.04.3 LTS; newer releases can use different wording or group the same choices differently. Consult the [official Ubuntu installation guide](https://ubuntu.com/desktop/docs/en/latest/tutorial/install-ubuntu-desktop/) for the current installer.

> **Important:** “Erase disk and install Ubuntu” is safe here only because the selected disk is the new VMware virtual disk. Do not choose it on a physical computer unless you intend to erase that physical disk.

## 1. Choose language and accessibility settings

Select your preferred language, review any accessibility options you need, and continue.

![Ubuntu installer language selection](/images/ubuntu/vmware/step1.png)

![Ubuntu installer accessibility options](/images/ubuntu/vmware/step2.png)

## 2. Select the keyboard layout

Choose the layout that matches the host keyboard. Use the test field to confirm punctuation and special keys.

![Ubuntu keyboard-layout selection](/images/ubuntu/vmware/step3.png)

## 3. Connect to the network

With the VMware adapter set to NAT, Ubuntu normally detects a wired connection automatically. You can install offline, but updates, codecs, and third-party drivers require internet access.

![Ubuntu installer network screen](/images/ubuntu/vmware/step4.png)

## 4. Start installation

Choose **Install Ubuntu** rather than the live-session option when the installer asks whether to try or install the system.

![Install Ubuntu option](/images/ubuntu/vmware/step5.png)

## 5. Choose interactive installation

Select the standard interactive/default installation. Depending on the Ubuntu release, the next screen may offer a default or extended application selection.

![Ubuntu interactive installation option](/images/ubuntu/vmware/step6.png)

![Ubuntu application selection](/images/ubuntu/vmware/step7.png)

## 6. Updates and third-party software

Enable update downloads during installation when the connection is reliable. Third-party drivers and media formats are optional; they can improve hardware and codec support, though a basic VMware lab usually works without them.

![Ubuntu optimisation and third-party software options](/images/ubuntu/vmware/step8.png)

## 7. Select the virtual disk

Choose **Erase disk and install Ubuntu**, verify that the target is the VMware virtual disk of roughly the size you created, and confirm the changes.

![Ubuntu virtual-disk setup](/images/ubuntu/vmware/step9.png)

## 8. Create the user account

Enter a name, computer name, lowercase username, and strong password. Require the password to log in so the lab reflects a normal security configuration.

![Ubuntu user-account setup](/images/ubuntu/vmware/step10.png)

## 9. Set the timezone

Select the correct region and city. The VM clock normally synchronises through the network after installation.

![Ubuntu timezone selection](/images/ubuntu/vmware/step11.png)

## 10. Review and install

Review the summary, begin installation, and wait while files are copied and packages are configured.

![Ubuntu installation summary before clicking Install](/images/ubuntu/vmware/step12.png)

## 11. Restart and disconnect the ISO

Select **Restart Now** when installation finishes.

![Ubuntu restart prompt](/images/ubuntu/vmware/step13.png)

If Ubuntu asks you to remove the installation medium, use VMware's **VM → Removable Devices → CD/DVD → Disconnect** command and press Enter. If the installer starts again, power off the VM and disconnect the ISO before the next boot.

## 12. Complete first-run setup

Review Ubuntu Pro and privacy options. Ubuntu Pro is optional for this lab; you can skip it. Sharing diagnostic information is also optional.

![Ubuntu Pro first-run screen with the option to skip](/images/ubuntu/vmware/step14.png)

![Ubuntu diagnostics preference](/images/ubuntu/vmware/step15.png)

![Ubuntu first-run completion screen with Open App Center](/images/ubuntu/vmware/step16.png)

## 13. Update the installed system

Open the terminal with `Ctrl + Alt + T` and run:

```bash
sudo apt update
sudo apt full-upgrade
sudo apt install open-vm-tools-desktop
```

Restart after significant updates. Then take a VMware snapshot named `Clean install` before beginning lab experiments.

## Verify the result

- Ubuntu reaches the login screen without the installer ISO.
- Display resizing works and the network is connected.
- `sudo apt update` completes without errors.
- `free -h`, `df -h`, and `ip address` show the expected resources.
