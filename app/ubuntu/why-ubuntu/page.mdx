# Why Ubuntu?

## Why use it for an operating-systems lab?

Ubuntu is a practical first Linux distribution because its installer is approachable, its hardware support is broad, and a large collection of documentation and packages is available. The Desktop edition provides a graphical environment while keeping the terminal and standard Linux administration tools close at hand.

For coursework, choose the latest **LTS (Long-Term Support)** release unless the instructor requires a specific version. Ubuntu LTS provides five years of standard security maintenance for packages in Main; coverage for other repositories and official flavours differs. Interim releases receive nine months of updates. See [Ubuntu's release and support cycle](https://ubuntu.com/about/release-cycle).

## Ubuntu and Debian

Ubuntu is built from Debian packages and uses the same `.deb` package format and APT package-management tools. It has its own release schedule, repositories, defaults, desktop integration, and commercial sponsor, Canonical. Ubuntu is therefore related to Debian, but it is not simply Debian with a different theme.

## Desktop, Server, and flavours

- **Ubuntu Desktop** includes a graphical desktop and common applications.
- **Ubuntu Server** focuses on server workloads and normally starts with a command-line interface.
- Official **Ubuntu flavours** use different desktop environments and default applications while sharing Ubuntu repositories.

This project uses Ubuntu Desktop because screenshots and a graphical installer are easier to follow in an introductory lab.

## What students can practise

- Files, directories, users, groups, and permissions
- Package installation and updates with APT
- Processes, services, logs, and system resources
- Shell commands and simple automation
- Virtual networking and remote access

> Ubuntu makes the first installation easier, but the Linux concepts in this guide also transfer to Debian and many other distributions.
