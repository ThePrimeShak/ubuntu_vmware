# Create an Ubuntu Virtual Machine

This page prepares the virtual hardware. The next page covers the Ubuntu installer itself.

The screenshots were captured with Ubuntu 24.04.3 and Workstation 17. They illustrate the wizard; use the resource values below rather than the older 20 GB disk and 4 GB memory shown in the screenshots.

## 1. Download and verify the Ubuntu ISO

Download the latest **Ubuntu Desktop LTS** image from the [official Ubuntu website](https://ubuntu.com/download/desktop). Avoid third-party mirrors unless they are listed by Ubuntu.

On Windows, verify the downloaded file against the SHA256 checksum published for that release:

```powershell
Get-FileHash .\ubuntu-*-desktop-amd64.iso -Algorithm SHA256
```

Compare the hash for the exact ISO filename with its entry in `SHA256SUMS`. A matching hash checks integrity; to authenticate the checksum file, also verify `SHA256SUMS.gpg` with the Ubuntu signing key as described in the [official verification guide](https://ubuntu.com/tutorials/how-to-verify-ubuntu).

## 2. Start the New Virtual Machine wizard

Open VMware Workstation Pro and select **File → New Virtual Machine**. Choose **Typical (recommended)** for this lab.

![VMware File menu with New Virtual Machine selected](/images/ubuntu/step1.png)

![New Virtual Machine wizard with Typical selected](/images/ubuntu/step2.png)

## 3. Select the installer image

Choose **Installer disc image file (ISO)**, browse to the Ubuntu ISO, and continue. VMware may recognise the release automatically.

![Ubuntu ISO selection and guest operating-system detection](/images/ubuntu/step3.png)

> If VMware offers **Easy Install**, you can use it for an automated setup. For this course, manually following the Ubuntu installer is more educational; choose the option to install the operating system later if you want to see every step.

For that manual path, select **I will install the operating system later**, choose the Ubuntu 64-bit guest type, and skip the Easy Install form. Before the first power-on, open **Customize Hardware → CD/DVD**, attach the ISO, and enable **Connect at power on**.

## 4. Complete Easy Install details, if enabled

When Easy Install is active, provide a full name, a lowercase username, and a strong password. Do not reuse an important personal password in a lab VM.

![VMware Easy Install account form](/images/ubuntu/step4.png)

## 5. Name and store the VM

Use a descriptive name such as `Ubuntu-Lab`. Store the VM on an internal SSD when possible and ensure the host drive has enough free space.

![Virtual-machine name and storage location](/images/ubuntu/step5.png)

## 6. Configure the virtual disk

Allocate at least **30 GB**. Ubuntu documents a 25 GB storage requirement, and the additional space leaves room for updates and lab files. A dynamically allocated virtual disk grows as data is written; the maximum size is not reserved immediately.

Either a single virtual-disk file or split files work. A single file can be slightly simpler; split files are easier to move onto filesystems with file-size limits.

![VMware virtual-disk capacity settings](/images/ubuntu/step6.png)

## 7. Review virtual hardware

Select **Customize Hardware** and review:

- **Memory:** at least 6 GB for Ubuntu Desktop 26.04 LTS, while leaving enough RAM for the host
- **Processors:** 2 virtual cores
- **Network Adapter:** NAT for uncomplicated internet access
- **CD/DVD:** the Ubuntu ISO must be connected at power on
- **Display:** 3D acceleration is optional

Do not assign all host CPU cores or memory to the VM. The host must remain responsive.

![VMware summary with the Customize Hardware button](/images/ubuntu/step7.png)

## 8. Power on the VM

Finish the wizard and start the VM. If prompted to download VMware Tools before Ubuntu is installed, skip it; Ubuntu uses the `open-vm-tools` packages after installation.

## Recommended settings at a glance

| Setting  | Value                                     |
| -------- | ----------------------------------------- |
| Guest OS | Latest Ubuntu 64-bit option available     |
| Firmware | UEFI                                      |
| Disk     | 30–40 GB, dynamically allocated           |
| Memory   | 6 GB or more for Ubuntu Desktop 26.04 LTS |
| CPU      | 2 virtual cores                           |
| Network  | NAT                                       |

Continue to **Install Ubuntu** in the sidebar when the Ubuntu installer appears.
